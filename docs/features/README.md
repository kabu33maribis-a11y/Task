# 追加機能 仕様書

このフォルダは、既存アプリへの追加機能を実装するための仕様書を置く場所です。

プロダクト全体の仕様（ルートの `SPEC.md`、`docs/AI再現用_要件仕様書.md` など）とは別に、機能単位の実装仕様をここに置きます。実装時は対象の仕様書を正として進めます。

## 仕様書一覧

| 機能 | ファイル | ステータス |
|---|---|---|
| リマインダ | [reminder_specification.md](./reminder_specification.md) | 実装済み |

## 新規仕様書の追加

1. このフォルダに `{機能名}_specification.md` を追加する。
2. 上表に行を追加する。
3. 少なくとも次を含める。
   - 目的
   - 対象範囲（初期リリースの対象 / 対象外）
   - ユーザー仕様
   - データ設計
   - 実装手順
   - 受け入れテスト
   - 未確定事項
