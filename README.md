# 個人用タスク管理ツール

「今日やることを簡単に管理し、あとから自分が何をしたか振り返れる」ための、軽量・シンプルなタスク管理アプリです。
（[仕様書](./個人用タスク管理ツール%20仕様書.md) に基づく MVP 実装）

## 技術構成

- **React 18 + Vite**（ビルド）
- **状態管理**: React `useReducer` + Context（依存ライブラリなし）
- **データ保存**: ブラウザの `localStorage`（キー: `taskmanager.v1`）に自動保存
  - 設定画面から **JSON バックアップ（書き出し／読み込み）** が可能
- **ドラッグ&ドロップ**: ブラウザ標準の HTML5 DnD（依存ゼロ）

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで表示された URL（既定 http://localhost:5173 ）を開きます。

本番ビルド:

```bash
npm run build
npm run preview
```

## 画面レイアウト

- **ノートPC（幅 1024px 以上）**: 1画面完結の **2ペイン**。左に **Today**、右に **Calendar** を並べ、ヘッダーから **Inbox / Log / 設定** をスライドオーバーで開きます。ページ全体はスクロールせず、各ペインが内部スクロール。
- **タブレット / スマホ（1024px 未満）**: 下部ナビ（Today / Calendar / Log / Inbox）のタブ切替。

## デザイン言語

「**色 = 達成の記録**」を軸にした、和紙(washi)＋墨(sumi)＋朱(shu) の3値配色。

- 未完了はすべて墨色。**完了した瞬間だけ朱色（朱印）が現れる** → 仕様の「完了履歴を資産にする」を視覚化。
- 「今日の3つ」は星ではなく **①②③ の連番**（＝最大3件という事実を符号化）。
- 見出しは明朝、数値（カレンダー・集計）は等幅。すべてOS内蔵フォントで、追加ダウンロードなし（高速表示）。

## 実装済み機能（MVP）

| 画面 | 内容 |
|---|---|
| **Today** | 当日タスク／「今日の3つ」（★・最大3件）／その他／未完了タスクの繰越表示（今日へ移動）／クイック追加 |
| **Calendar** | 月表示＋各日の完了・未完了件数／日付クリックで一覧／タスクを別日へD&Dで予定日変更 |
| **Log** | 月次集計（完了・未完了・翌月繰越・完了率）／カテゴリ別完了数／完了履歴／「今月やったことをコピー」（Markdown） |
| **Inbox** | 日付未定タスクの一時保管／今日・明日・日付指定で予定日設定 |

- タスクの追加・編集（インラインで完結、モーダル最小）・削除（Undo トースト付き）・完了
- カテゴリの追加・編集・削除（設定画面）
- 予定日（`scheduled_date`）と完了日時（`completed_at`）を分離管理
- PC / タブレット / スマホ対応（PCは上部ナビ、モバイルは下部ナビ）

## 設計上の判断メモ

- **翌月繰越**: 仕様に定義式がなかったため、「当月予定・未完了・予定日超過」のタスク数と定義しています（要調整）。
- **今日の3つ（★）**: 1日あたり最大3件。日付未定（Inbox）のタスクには設定できません。
- **未完了タスク**: 予定日を過ぎても自動で日付を変更せず、Today に繰越表示（履歴を残すため）。
- **繰り返し・検索・ショートカット等**は仕様の「MVP後」に従い未実装（データ構造 `recurrence` は保持）。

## データ構造

`localStorage` に以下の形で保存されます。

```json
{
  "version": 1,
  "tasks": [
    {
      "id", "title", "status", "scheduled_date", "completed_at",
      "category_id", "is_today_top3", "sort_order", "recurrence",
      "created_at", "updated_at"
    }
  ],
  "categories": [{ "id", "name", "sort_order", "created_at", "updated_at" }]
}
```
